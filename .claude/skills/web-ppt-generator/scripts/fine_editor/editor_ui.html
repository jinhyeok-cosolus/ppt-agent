선택된 요소

슬라이드에서 Text 또는 Image를 클릭해 선택하세요.

선택 후 드래그로 이동하거나, 모서리(Text·Image 공통)·좌우 변(Text 전용) 핸들로 크기를 조절할 수 있습니다.

Ctrl(또는 Shift) + 클릭으로 여러 요소를 함께 선택해 한 번에 이동할 수 있습니다.
Text는 더블클릭하면 그 자리에서 바로 내용을 수정할 수 있습니다.

이 도구는 문구/좌표/크기/이미지 교체 같은 최종 미세 수정 전용입니다. Layout 재설계, 새 도형/Connector 구조 변경, Color·Typography System 수정은 기존 Agent 수정 워크플로우([7])를 사용하세요.

수정이 끝나면 "최종 확정" 버튼 하나로 저장부터 공유용 HTML 생성까지 끝낼 수 있습니다 — 별도로 index.html 파일을 찾아 열거나 관리할 필요가 없습니다.
