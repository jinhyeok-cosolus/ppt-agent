# COSOLUS PPT Visual Style

> 본 문서는 COSOLUS PPT 전체 Deck에 공통으로 적용하는 시각적 스타일 기준을 정의한다.
> Hard Rule을 변경하거나 대체하지 않으며, Hard Rule을 준수하는 범위에서 전체 슬라이드가 하나의 Deck처럼 보이도록 시각적 일관성을 유지하기 위한 기준이다.

## 1. Overall Mood
- 전문적이고 신뢰감 있는 B2B 기업 프레젠테이션 분위기를 기본으로 한다.
- 화학소재, 배터리, 친환경 공정, 기술기업에 어울리는 차분하고 정돈된 인상을 유지한다.
- 지나치게 화려하거나 마케팅성 장식이 강한 스타일은 지양한다.
- 전체 Deck은 깔끔하고 현대적이며 정보 전달 중심으로 구성한다.

## 2. Visual Consistency
- 슬라이드마다 완전히 다른 스타일을 새로 만들지 않는다.
- 동일한 역할의 카드, 라벨, 강조 박스, 선, 아이콘은 동일한 시각 언어를 유지한다.
- 동일한 정보 위계는 동일한 표현 방식으로 반복한다.
- 표지, 본문, 데이터, 마무리 슬라이드가 서로 다른 역할을 가지더라도 하나의 PPT Deck으로 보이도록 통일한다.

## 3. White Space & Density
- 충분한 여백을 확보해 정보가 답답하게 보이지 않도록 한다.
- 빈 공간을 억지로 채우기 위한 장식 요소를 추가하지 않는다.
- 한쪽 영역에 콘텐츠가 과도하게 몰리지 않도록 시각적 균형을 유지한다.
- 정보가 많을 경우 글자 크기를 줄이는 것보다 요약, 분할, 레이아웃 변경을 우선한다.

## 4. Information Hierarchy
- 슬라이드에서 가장 중요한 메시지가 가장 먼저 인식되도록 한다.
- 제목, 핵심 메시지, 본문, 보조 정보의 위계를 명확하게 구분한다.
- 핵심 수치나 결론은 일반 본문보다 강한 시각적 위계로 표현한다.
- 모든 요소를 동일한 크기와 강도로 강조하지 않는다.

## 5. Cards & Highlight Areas
- 카드와 강조 박스는 정보 구분이 필요한 경우에만 사용한다.
- 동일한 역할의 카드는 크기, 모서리, 내부 여백, 제목 위치를 일관되게 유지한다.
- 카드 사용이 불필요한 경우 선, 여백, 정렬만으로 정보를 구분하는 방식을 우선한다.
- 한 슬라이드에서 과도한 카드 분할을 지양한다.

## 6. Lines & Decorative Elements
- 선과 구분선은 정보 구분 또는 시선 유도에 필요한 최소 수준으로 사용한다.
- 장식 목적의 복잡한 패턴, 과도한 그림자, 입체 효과는 지양한다.
- 그래픽 요소는 메시지를 보조해야 하며 콘텐츠보다 강하게 보이지 않도록 한다.

## 7. Image Treatment
- 이미지가 있는 경우 텍스트와 조화를 이루도록 배치한다.
- 실제 회사, 기술, 연구, 생산, 제품 이미지를 사용할 수 있는 경우 우선 활용한다.
- 이미지가 지나치게 강한 경우 저채도, 투명도, 브랜드 컬러 오버레이 등으로 시각적 강도를 조정할 수 있다.
- 이미지의 중요한 피사체가 잘리지 않도록 Crop을 조정한다.
- 동일 Deck 내 이미지 처리 방식은 가능한 한 일관되게 유지한다.

## 8. Data Visualization
- 그래프, 표, KPI는 디자인 장식보다 정보 전달을 우선한다.
- 핵심 데이터만 선택적으로 강조한다.
- 데이터와 함께 해석 또는 핵심 인사이트를 제공할 수 있는 경우 함께 배치한다.
- 불필요한 3D 효과, 과도한 색상 사용, 복잡한 범례는 지양한다.

## 9. Reference Use
- Visual Reference는 전체 Deck의 분위기, 여백감, 정보 위계, 카드/강조 영역의 표현 방식, 이미지와 텍스트의 조화만 참고한다.
- Reference의 폰트, 색상, 로고, 고유 장식 요소를 그대로 복제하지 않는다.
- Hard Rule과 충돌하는 Reference 요소는 적용하지 않는다.

## Priority
본 문서는 전역 적용 우선순위를 자체적으로 정의하지 않는다. Hard Rule을 포함한 전체 문서 간 적용 우선순위는 `.claude/skills/web-ppt-generator/references/design-rules.md`의 "적용 우선순위"를 따른다. 본 문서(Visual Style)가 우선순위 체계 내 어느 위치에 있는지도 해당 문서의 기준을 따른다.
