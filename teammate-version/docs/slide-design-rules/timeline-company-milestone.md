# Timeline / Company Milestone Layout

## 1. Layout Purpose

### 사용 목적
다음과 같이 시간의 흐름과 단계별 변화를 보여주는 콘텐츠에 사용한다.

- 회사 연혁
- 기술 개발 이력
- 프로젝트 진행 과정
- 사업 추진 일정
- 제품 개발 Roadmap
- 주요 성과 및 성장 과정
- 과거 → 현재 → 미래 목표

### 핵심 구조

[START/TODAY] ── Milestone 1 ── Milestone 2 ── Milestone 3 ── Milestone 4 ── [GOAL]

- 하나의 수평 Timeline을 중심축으로 사용한다.
- Timeline 양 끝에 Start / Goal Marker를 배치한다.
- 각 Milestone은 Timeline 위·아래로 교차 배치한다.
- 각 Milestone은 Point + Date + Connector + Content로 구성한다.

---

## 2. Core Layout Structure

### Timeline

슬라이드 콘텐츠 영역을 가로지르는 하나의 긴 수평선을 배치한다.

- 좌 → 우 방향으로 시간의 흐름을 표현한다.
- Timeline은 반드시 수평을 유지한다.
- Milestone Point는 Timeline 위에 정확하게 정렬한다.
- Timeline 전체는 콘텐츠 영역의 주요 시각적 중심축 역할을 한다.
- Timeline의 정확한 길이와 위치는 제목 영역 및 전체 콘텐츠 양을 고려하여 조정한다.

---

## 3. Start / Goal Marker

Timeline의 양 끝에는 일반 Milestone과 구분되는 Marker를 배치한다.

구조:

[START] ───────── Timeline ───────── [GOAL]

사용 가능한 Label 예시:

Start Marker
- TODAY
- START
- 설립
- 현재

Goal Marker
- GOAL
- VISION
- TARGET
- 목표

### 디자인 원칙

- Start와 Goal은 동일 계열의 형태를 사용한다.
- 일반 Milestone Point보다 크게 표현한다.
- 양쪽 Marker의 크기와 시각적 무게를 균형 있게 구성한다.
- Marker 내부에 짧은 Label을 삽입할 수 있다.

### 권장 형태

- Map Pin
- Location Marker
- Circle Marker
- 기타 시작점/도착점을 명확하게 표현할 수 있는 단순한 Graphic

Reference와 동일한 Map Pin 형태를 우선적으로 고려하되,
전체 PPT 디자인과 어울리지 않을 경우 단순한 Circle Marker 등으로 변경할 수 있다.

---

## 4. Milestone Structure

각 Milestone은 기본적으로 다음 요소로 구성한다.

1. Timeline Point
2. Year / Date
3. Vertical Connector
4. Milestone Title
5. Description

기본 구조:

        TITLE
        Description
        │
        │
YEAR ───●────────

또는

────────●─── YEAR
        │
        │
        TITLE
        Description

각 요소는 하나의 Milestone Group으로 인식될 수 있도록 배치한다.

---

## 5. Timeline Point

각 Milestone의 위치는 Timeline 위의 작은 Point로 표시한다.

- Point는 Timeline 중앙선 위에 배치한다.
- 모든 Point의 기본 크기는 동일하게 유지한다.
- Start / Goal Marker보다 작게 표현한다.
- Point는 해당 Milestone의 시간적 위치를 나타내는 기준점 역할을 한다.

---

## 6. Year / Date

각 Milestone Point 인접 영역에 해당 시점을 표시한다.

예:

2021  
2022  
2023  
2024

또는

2026.01  
2026.03  
2026.07

### 배치 원칙

- Timeline과 가까운 위치에 배치한다.
- 해당 Milestone Point와 명확하게 연결되어 보여야 한다.
- 인접 Milestone의 Year와 혼동되지 않도록 충분한 간격을 확보한다.
- 동일 슬라이드에서는 날짜 표기 형식을 통일한다.

---

## 7. Vertical Connector

각 Timeline Point에서 Milestone Content 방향으로 세로 Connector를 연결한다.

### 원칙

- Connector는 Point와 Content의 관계를 명확하게 보여주는 역할만 한다.
- 필요 이상으로 길게 사용하지 않는다.
- 인접 Milestone의 Content 영역을 침범하지 않는다.
- Content 위치에 따라 Connector 길이는 자동 조정할 수 있다.

---

## 8. Milestone Content

각 Milestone Content는 기본적으로 다음 구조를 사용한다.

Milestone Title

Description

예:

기술 개발 완료

핵심 소재 합성 기술 개발 및  
Lab Scale 검증 완료

### Title

- 해당 Milestone의 핵심 사건을 짧게 표현한다.
- 가능하면 한 줄로 구성한다.

### Description

- Milestone에 대한 보조 설명을 제공한다.
- 1~3줄을 권장한다.
- 장문의 설명보다 핵심 사건과 성과 중심으로 축약한다.

---

## 9. Alternating Layout

Milestone Content는 Timeline을 기준으로 위/아래에 교차 배치하는 것을 기본으로 한다.

기본 패턴:

Milestone 01 → Upper  
Milestone 02 → Lower  
Milestone 03 → Upper  
Milestone 04 → Lower

구조:

      M1                 M3
      │                  │
──────●────────●─────────●────────●──────
               │                  │
               M2                 M4

### 기본 원칙

가능한 경우 Upper / Lower 교차 구조를 유지한다.

이를 통해:

- Timeline의 단조로움을 방지하고
- Content 영역을 넓게 활용하며
- 각 Milestone을 명확하게 구분한다.

### 예외

다음 상황에서는 AI가 배치를 조정할 수 있다.

- 설명 길이가 크게 다른 경우
- Milestone 간 공간 충돌이 발생하는 경우
- 이미지 또는 Icon이 포함되는 경우
- 특정 Milestone을 강조해야 하는 경우

단, 전체적인 상·하 시각적 균형은 유지한다.

---

## 10. Milestone Spacing

Milestone 간 기본 간격은 균등 배치를 우선한다.

START ── M1 ── M2 ── M3 ── M4 ── GOAL

### 일반 연혁

실제 연도 차이가 중요하지 않은 경우:

→ 균등 간격 사용

### 시간 간격 자체가 중요한 경우

시간 차이 자체를 전달해야 한다면:

→ 실제 기간을 고려하여 Point 간격을 조정할 수 있다.

단, 지나친 비례 적용으로 특정 구간이 과도하게 비거나 밀집되지 않도록 한다.

---

## 11. Milestone Visual Grouping

각 Milestone은 다음 요소가 하나의 시각적 그룹으로 인식되어야 한다.

Point  
+ Year  
+ Connector  
+ Title  
+ Description

필요한 경우 동일 Milestone에 동일 Accent Color를 적용하여 그룹 관계를 강화할 수 있다.

단, 색상 선택 및 전체 Color System은 공통 Design Hard Rule을 따른다.

---

## 12. Number of Milestones

### 권장 범위

3~6개

#### 3개
- Timeline을 넓게 사용한다.
- 각 Content 영역을 충분히 확보한다.

#### 4개
- Reference 이미지와 가장 유사한 기본 구성.
- Upper / Lower / Upper / Lower

#### 5개
- 교차 구조를 유지하면서 간격을 조정한다.

#### 6개
- Milestone Description을 축약하고 각 Content 영역의 폭을 조정한다.

#### 7개 이상
현재 Layout을 강제로 사용하지 않는다.

다음 Layout을 우선 검토한다.

- Multi-row Timeline
- Vertical Timeline
- Phase Roadmap
- History Table

정보 밀도가 지나치게 높아지는 경우 슬라이드를 2장 이상으로 분리하는 것도 허용한다.

---

## 13. Optional Elements

내용 전달에 도움이 되는 경우 Milestone에 다음 요소를 추가할 수 있다.

- Icon
- 핵심 성과 수치
- 제품 이미지
- 인증 마크
- 국가 / 지역 정보
- 특허
- 공장
- 수출
- 투자
- 양산 등의 상징 Graphic

단, Optional Element가 Timeline보다 시각적으로 우선하지 않도록 한다.

---

## 14. AI Layout Selection Rule

입력 콘텐츠가 다음과 같은 구조를 가지고 있으면 본 Layout을 우선 검토한다.

- 연도별 회사 연혁
- 주요 사업 성과
- 기술 개발 단계
- 제품 개발 과정
- 프로젝트 진행 과정
- 투자 / 공장 / 양산 이력
- 중장기 Roadmap
- 과거 → 현재 → 미래 구조

예:

2019 회사 설립  
2021 연구소 설립  
2023 Pilot 설비 구축  
2025 양산라인 구축  
2030 Global Market 진출

→ Timeline / Milestone Layout 우선 검토

---

## 15. Layout-Specific Hard Rules

본 Layout을 선택한 경우 다음 구조는 반드시 유지한다.

1. 좌 → 우 방향의 Horizontal Timeline
2. Timeline 양 끝의 Start / Goal Marker
3. Timeline 위에 배치되는 Milestone Point
4. 각 Point에 대응되는 Year / Date
5. Point와 Content를 연결하는 Vertical Connector
6. Milestone Title + Description 구조
7. Milestone Content의 Upper / Lower 분산 배치
8. 각 Milestone이 독립적인 시각적 Group으로 식별될 것

---

## 16. Layout-Specific Soft Rules

다음 요소는 콘텐츠 특성에 따라 조정할 수 있다.

- Timeline의 정확한 길이와 높이
- Start / Goal Marker 형태
- Milestone 간 간격
- Vertical Connector 길이
- Content 영역의 폭과 높이
- Upper / Lower 배치 순서
- Accent Color 적용 방식
- Icon 사용 여부
- Description 길이
- 실제 연도 간격의 비례 표현 여부

단,

Start → Timeline → Milestone → Goal

이라는 좌→우 시간 흐름과

Point → Date → Content

간의 관계는 명확하게 유지한다.

---

## 17. Priority

본 Layout MD는 Timeline / Milestone 슬라이드의 구조와 정보 배치 방식을 정의한다.

폰트, 글씨 크기, 제목/부제목 위치, Brand Color, 공통 브랜드 요소,
페이지 번호 및 기본 디자인 품질 기준은 별도의 공통 Design Hard Rule을 따른다.

본 Layout MD와 공통 Design Hard Rule이 충돌하는 경우
공통 Design Hard Rule을 우선 적용한다.
