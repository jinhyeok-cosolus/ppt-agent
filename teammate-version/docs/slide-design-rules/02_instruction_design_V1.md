# Company Introduction

## Purpose
회사의 정체성, 핵심 메시지 및 기본 정보를 외부 고객이 빠르게 이해할 수 있도록 전달하는 회사소개 슬라이드.

## Layout
- 좌측의 주요 정보 영역과 우측의 세로 이미지 영역으로 구성하는 2단 구조를 기본으로 한다.
- 좌측 영역을 주요 콘텐츠 영역으로 사용한다.
- 우측 이미지 영역은 슬라이드 높이를 적극적으로 활용한다.
- 좌측 상단에 Company 라벨과 회사소개 제목을 배치한다.
- 제목 아래에 회사의 정체성을 나타내는 핵심 메시지를 우선 배치한다.
- 핵심 메시지 아래에 기업 기본정보 영역을 배치한다.
- 기업 기본정보는 '항목명 + 내용' 구조로 정리한다.
- 각 정보 항목은 일정한 간격과 정렬 기준을 유지한다.

## Recommended Information
기업 기본정보는 제공된 자료 중 외부 청중에게 필요한 핵심 정보를 우선 사용한다.


- 기업명
- 대표자
- 임직원
- 소재지
- 비전

※ 모든 항목을 반드시 사용할 필요는 없으며 제공된 정보와 PPT 목적에 따라 선택한다.

## Typography Flexibility

- 슬라이드 제목과 부제목은 공통 Design Hard Rule에서 지정한 폰트 및 위계 규칙을 따른다.
- 제목과 부제목을 제외한 본문, 기업 기본정보, 항목명, 수치, 캡션, 보조 문구 등의 폰트는 본 Layout MD에서 특정 서체·굵기·크기로 고정하지 않는다.
- 본문 Typography는 정보의 역할, 콘텐츠 양, 이미지와의 균형, 전체 레이아웃의 시각적 위계에 맞게 PPT 제작 Agent가 자율적으로 조정할 수 있다.
- 동일한 역할을 수행하는 텍스트는 슬라이드 내부에서 일관된 Typography를 유지한다.
- 폰트 선택과 크기 조정은 가독성과 정보 위계를 우선하며, 장식적인 이유만으로 과도하게 다양한 서체·굵기·크기를 혼용하지 않는다.
- 콘텐츠가 많다는 이유만으로 본문을 지나치게 축소하기보다 정보 선별, 문장 축약, 영역 재배치를 우선 고려한다.

## Visual Style
- 핵심 메시지를 일반 기업정보보다 높은 시각적 위계로 표현한다.
- 기업정보 영역은 장식적인 카드보다 정돈된 정보 구조를 우선한다.
- 항목명과 내용을 명확하게 구분한다.
- 구분선 등은 정보 구분에 필요한 최소 수준으로 사용한다.
- 우측 이미지는 본문보다 시각적으로 지나치게 강하지 않도록 조절한다.

## Shared Image Asset Rule

회사소개 슬라이드에서 실제 회사 사진, 사업장 사진, 연구시설, 생산시설, 제품 이미지, 지도 등 시각 회사소개 슬라이드에서 이미지가 필요한 경우 다음 공용 이미지 경로를 우선 탐색한다.

`C:\Users\pc\Desktop\강진혁\ppt용\VS PPT 제작\docs\brand-assets\images`

### Asset Search Rule

- 위 `images` 폴더뿐 아니라 모든 하위 폴더를 재귀적으로 탐색한다.
- 이미지 종류에 따라 적절한 하위 폴더의 자산을 우선 사용한다.
- 폴더 구조는 향후 추가될 수 있으므로 특정 하위 폴더 목록에만 탐색 범위를 제한하지 않는다.

### Asset Priority
1. 위 공용 이미지 폴더에 목적에 적합한 실제 회사 자산이 존재하는지 먼저 확인한다.
2. 적합한 자산이 있으면 해당 이미지를 우선 사용한다.
3. 이미지 파일명과 실제 이미지 내용을 함께 확인하여 슬라이드의 정보와 가장 관련성이 높은 자산을 선택한다.
4. 적합한 공용 이미지가 없는 경우에만 다른 이미지 소스 또는 별도의 시각화 방식을 검토한다.
5. 회사와 직접 관련된 공용 이미지가 존재하는데 일반적인 스톡 이미지를 대신 사용하는 것은 지양한다.

### Image Selection
다음과 같이 콘텐츠 의미와 이미지 유형을 연결하여 선택한다.

- 본사 / 회사 위치 → 본사 이미지, 위치 지도, 사업장 위치 시각화
- 연구소 / R&D → 연구실, 분석장비, 연구시설 이미지
- 생산 / 사업장 → 공장 외관, 생산라인, 생산설비 이미지
- 제품 / 기술 → 실제 제품, 소재, 공정 또는 기술 관련 이미지
- 복수 사업장 / 지역 정보 → 지도 또는 사업장 위치 이미지

파일명만으로 용도를 확정하지 말고 가능한 경우 실제 이미지 내용을 확인한 후 사용한다.

### Location / Map Asset
회사 주소, 본사, 연구소, 공장 등 지리적 정보가 포함되고 공용 이미지 폴더에 적합한 지도 자산이 존재하는 경우 해당 지도 이미지를 적극적으로 활용할 수 있다.

예:
- 대한민국 전체 지도에서 회사 주요 지역을 강조한 이미지
- 특정 광역 지역을 확대하여 보여주는 이미지
- 본사·연구소·공장 위치를 표시한 지도 이미지

지도 자산을 사용할 경우:
- 주소 텍스트를 단순 반복하기보다 지도와 주소 정보를 상호 보완적으로 구성한다.
- 지도 자체가 핵심 콘텐츠가 아니라면 Company Facts보다 시각적 위계를 높이지 않는다.
- 등록된 지도 자산이 이미 존재하면 동일 목적의 지도를 임의로 새로 생성하지 않고 기존 자산을 우선 사용한다.
- 지도 색상 및 주변 그래픽은 `00_design-system.md`의 Brand Color Rule과 충돌하지 않도록 한다.

### Layout Adaptation
공용 이미지 자산의 비율과 콘텐츠 중요도에 따라 기본 2단 구조를 유연하게 조정할 수 있다.

예:
- 세로형 회사/시설 사진 → 우측 세로 이미지 영역 유지
- 가로형 사업장 사진 → 우측 영역을 확대하거나 하단 이미지 영역으로 재구성
- 지도/지역 시각화 → 지도 가독성을 확보할 수 있도록 이미지 영역 확대
- 복수의 시설 사진 → 2~3개 이미지 그리드 또는 대표 이미지 + 보조 이미지 구조 검토

단, 이미지 배치를 위해 Company Facts의 가독성을 훼손하거나 지나치게 많은 이미지를 한 슬라이드에 삽입하지 않는다.

## Soft Rules
- 회사 핵심 메시지는 회사의 정체성과 사업 방향이 드러나는 1~2줄로 요약한다.
- 제공된 회사 자료를 기반으로 핵심 메시지를 작성하며 근거 없는 내용을 임의로 추가하지 않는다.
- 기업 기본정보는 외부 청중에게 필요한 정보만 선별한다.
- 정보가 많을 경우 글자 크기를 줄이는 것보다 중요도가 낮은 정보를 제거하거나 다른 슬라이드로 분리하는 것을 우선한다.
- 항목명과 내용의 정렬을 일관되게 유지한다.
- 우측 이미지는 회사의 기술, 연구, 생산, 제품 등 회사의 정체성을 보여주는 이미지를 우선 사용한다.
- 적합한 실제 회사 이미지가 제공되었거나 공용 이미지 폴더에 존재하는 경우 해당 이미지를 우선 사용한다.
- 이미지가 너무 강한 경우 저채도, 흑백, 투명도 또는 브랜드 컬러 오버레이 등을 활용해 시각적 강도를 낮출 수 있다.
- 이미지의 중요한 피사체가 잘리지 않도록 Crop 위치를 조절한다.
- 핵심 메시지와 기업정보 사이에 충분한 여백을 확보한다.
- 콘텐츠 양과 선택한 이미지 자산의 특성에 따라 좌측 정보 영역과 우측 이미지 영역의 비율을 조정할 수 있다.

## Avoid
- 회사 기본정보를 긴 문장으로 나열하는 구성
- 모든 정보를 동일한 시각적 강도로 표현하는 구성
- 정보가 많다는 이유로 글자 크기를 과도하게 축소하는 것
- 회사와 관련 없는 일반적인 스톡 이미지 사용
- 공용 이미지 폴더에 적합한 회사 자산이 있음에도 이를 확인하지 않고 외부 이미지를 우선 사용하는 것
- 이미지가 본문보다 지나치게 강조되는 구성
- 과도한 카드, 그림자, 테두리 및 장식 요소 사용
- 이미지 비율을 강제로 변형하여 왜곡하는 것
