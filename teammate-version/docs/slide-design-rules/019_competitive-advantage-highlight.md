## 1. 콘텐츠 레이아웃

```
[제목 블록] Technology (에이브로우) + 경쟁력 – [솔루션 2] … (한글 대제목, 2행)

┌ 항목 열 ┬──── COSOLUS ────┬──── BTR ────┬──── Vianode ────┐
│ 기업명  │  (로고 워드마크)  │    BTR      │    Vianode      │
│ 국가    │   🇰🇷 Korea      │ 🇨🇳 China    │ 🇳🇴 Norway       │
│ 기술    │ 유도가열 ~950℃   │ 전기로 3000℃ │ 대류가열 3000℃   │
│ 처리시간 │   1분 이내       │  ~24시간     │  ~48시간         │
│ 특징    │ 낮은 에너지 소비량 │ 높은 에너지…  │ 보통 수준…       │
└─────────┴─────────────────┴─────────────┴─────────────────┘
   좁음        강조 카드          동일 폭        동일 폭
```

- 표는 슬라이드 세로 중앙보다 약간 위, 좌우 여백 대칭. 하단 1/6은 비워 둠(여백으로 마무리)
- 열 폭: 항목 열이 가장 좁고, 비교 3사는 동일 폭. **자사 열만 카드로 승격**돼 실제 폭은 같아도 시각 무게가 다름
- 표 외곽선·세로 구분선 없음. **가로 라인만으로 행을 구분**하는 오픈형 표

## 2. 자사 강조 방식 (이 슬라이드의 핵심 패턴)

경쟁 우위를 "글자 강조"가 아니라 **열 전체의 형식 차이**로 만든다.

1. **열 단위 솔리드 카드**: 자사 열만 teal 채움(`#349886`) + 상단 라운드 모서리 카드. 경쟁사 열은 흰 배경 그대로 → 대비만으로 시선이 먼저 자사에 꽂힌다.
2. **텍스트 반전**: 카드 안 텍스트는 흰색, 카드 안 행 구분선도 흰 반투명. 밖은 어두운 회색 텍스트 + 옅은 회색 선. 같은 표에 **두 개의 색 체계**가 공존.
3. **로고 vs 텍스트명**: 자사 칸은 CI 워드마크, 경쟁사 칸은 일반 텍스트명 → 브랜드 자산의 비대칭 노출.
4. **수치의 자기 증명**: 1분 이내 / ~24시간 / ~48시간 처럼 **단위 자릿수가 다른 값**을 나란히 두어 문장 설명 없이 격차가 읽히게 함. 온도(950℃ vs 3000℃)도 동일 전략.
5. **특징 행의 대구(對句)**: 세 열이 같은 문형·같은 줄 수로 서술(에너지 소비량 / 공정 연속성 / 가열 방식) → 항목이 정렬돼 우열이 자동 비교된다.
6. **카드가 표 밖으로 넘침**: 카드 상단이 표 첫 라인보다 위로, 하단이 마지막 라인보다 아래로 살짝 벗어나 물리적으로 "튀어나온" 느낌을 준다.

강조에 화살표·별표·"BEST" 뱃지 같은 장식을 쓰지 않는다. 형식 차이만으로 처리.

## 4. 그래픽 요소

- **국기 이모지/아이콘**: 국가 행에만 사용, 국가명 옆 소형 배치. 나머지 행은 순수 텍스트
- **행 구분선 2종**: 얇은 헤어라인(행 구분) + 상대적으로 굵고 진한 라인(표 상·하단 및 처리시간 행 아래 구획)
- 카드 내부에도 동일한 행 구분선이 흰색으로 이어져 **표 그리드가 카드를 관통**

## 6. 재사용 가능한 패턴

**"경쟁사 비교표 — 자사 열 카드 강조" 모듈**

- 좌측 항목 라벨 열(좁게, 약하게) + 비교 대상 N열(동일 폭)
- 자사 열은 항상 **첫 번째 비교 열**에 두고 solid 카드 + 흰 텍스트로 반전
- 세로선 없이 가로 라인만, 표 상·하단은 굵은 라인으로 닫음
- 행 순서: 정체성(사명·국가) → 방식(기술) → 성과 수치(시간) → 서술 특징
- 열 3~4개까지 확장 가능. 그 이상은 카드 대비가 약해짐

## 7. 콘텐츠 레이아웃 이슈

- 좌측 항목 라벨이 열 폭 부족으로 한 글자씩 세로로 쪼개짐(`기업 명`, `국 가`, `처 리 시 간`) → 라벨 열 폭 확대 또는 라벨 축약 필요
- 자사 카드 하단에서 텍스트가 카드 밖으로 잘림(`직접 가열` 행 절단) → 카드 높이/행 높이 재계산 필요
- `Vianode`, `China`, `(3000℃)` 등이 열 폭에 걸려 어색하게 줄바꿈 → 열 폭 또는 폰트 크기 조정 필요
- 제목이 2행으로 넘치며 에이브로우 `Technology`와 겹침
