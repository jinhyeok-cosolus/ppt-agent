# 디자인 규칙 (design-rules.md)

> 이 문서는 웹PPT/pptx 생성 시 항상 먼저 참조하는 디자인 규칙이다. **고정 규칙**과 **가변 규칙**으로 구분한다.
> 신규 규칙은 LLM이 스스로 "일반화 가능하다"고 판단하더라도 **사용자의 명시적 승인 없이는 본문에 반영하지 않는다.** 승인 전 후보는 하단 "검토 대기 후보" 섹션에만 기록한다.

## 고정 규칙 (반드시 유지)

> 회사 로고, 브랜드 요소, 지정된 표지 등. 사용자가 별도로 명시하지 않는 한 레퍼런스 분석 대상에서 제외되며, 사용자가 직접 지정할 때만 이 섹션에 추가한다.

- (아직 등록된 고정 규칙 없음 — 최초 프로젝트 진행 시 사용자에게 브랜드 자산 유무를 확인하고, 있다면 `/docs/brand-assets/`에 등록한 뒤 이곳에 규칙을 추가한다.)

예시 형식:
```
### 로고
- 파일: /docs/brand-assets/logo.svg
- 위치: 모든 슬라이드 우측 하단, 24x24px 여백 확보
- 표지 슬라이드는 예외적으로 중앙 상단 배치

### 브랜드 컬러
- Primary: #000000 (사용자 확정 후 기입)
- 사용 규칙: ...
```

## 가변 규칙 (레퍼런스 참고, 목적에 맞게 구성)

> 슬라이드 레이아웃, 표/차트 스타일, 정보 시각화, 강조 방식 등. 레퍼런스 자료 분석 후 사용자 승인을 받아 이곳에 추가한다.

- **사업장 위치 소개**: 지도(Generated Image) + Location Marker/Connector/Card(PPT Object) + 실사진(External Image) 3분리 원칙(v3). 지도 자체는 이미지 생성 기능으로 만들고 그 위에 PPT 객체(Map Pin, 2~3 Segment 점선, 사업장 카드)를 얹는 구조이며, 실사진 없이 임의로 건물 사진을 생성하는 것은 금지. **주의**: 이미지 생성 도구가 파이프라인에 없는 동안은 v2의 PPT 도형 기반 개략 지도를 임시 대체재로 사용한다(상세: 문서 상단 유의사항). 색상은 별도 지정 없이 Hard Rule Brand Color를 그대로 참조. 상세 규칙은 [`docs/slide-design-rules/021_business-site-map.md`](../../../../docs/slide-design-rules/021_business-site-map.md) 참고 (2026-08-14 v1 등록 → 2026-08-18 v2 → 2026-08-18 v3, 모두 코솔러스-넥스모션테스트 프로젝트에서 사용자 승인).

## 검토 대기 후보 (사용자 승인 대기)

> content-designer가 [9] 단계에서 "일반화 가능하다"고 판단했지만 아직 사용자 승인을 받지 못한 후보. 승인되면 위 섹션으로 이동하고 여기서 삭제, 거절되면 사유와 함께 여기 보존(재제안 방지).
