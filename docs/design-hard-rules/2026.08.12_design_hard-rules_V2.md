# PPT Design Hard Rules
PPT 제작 시 모든 디자인 및 레이아웃에 공통으로 적용하는 최소 디자인 Hard Rule이다.
개별 레이아웃의 구체적인 구성 방식은 별도의 디자인/Layout MD에서 정의한다.
## 1. 슬라이드 규격
모든 PPT는 16:9 비율을 기본 규격으로 사용한다.
## 2. 폰트
PPT 전체의 기본 글씨체(Font Family)는 Pretendard로 통일한다. 표지를 포함한 모든 슬라이드에서 Pretendard 외 다른 서체(예: G마켓 산스 등)를 사용하지 않는다.
Pretendard 내 Weight(Light/Regular/Medium/SemiBold/Bold/ExtraBold 등)는 정보 위계와 강조 수준에 따라 자유롭게 사용할 수 있으며, 역할별 구체적인 Weight 적용은 Claude_PPT_Design_System.md에서 정의한다.
지정되지 않은 폰트 패밀리를 임의로 혼용하지 않는다.
## 3. 글씨 크기
역할별(제목/본문/각주 등) 구체적인 글씨 크기는 Claude_PPT_Design_System.md에서 정의한다. 본 Hard Rule은 Font Family(Pretendard 통일)만 고정하며, 크기 수치는 고정하지 않는다.
## 4. 제목 및 부제목
본문 슬라이드는 내용을 명확히 나타내는 제목을 기본적으로 포함한다.
필요한 경우 제목을 보완하는 부제목 또는 한 줄 핵심 메시지를 사용할 수 있다.
동일한 역할의 제목과 부제목은 PPT 전체에서 일관된 위계와 스타일을 유지한다.
표지·Section Divider 등 특수 슬라이드를 제외한 **일반 콘텐츠 슬라이드의 Main Title**은 아래 "9. 공통 Header System"에서 정의하는 고정 위치·크기·Section Label 규칙을 따른다. Main Title을 보완하는 부제목(1~2줄 설명문)은 아래 "12. Main Title Supporting Message"에서 정의하는 Optional 공통 요소 규칙을 따르며, 그 외 정확한 Gap 등 세부 표현 방식은 적용되는 디자인/Layout MD의 판단을 따른다.
## 5. Brand Color
### Primary Colors
Primary(구 Cosolus Teal) — #067875
회사의 기본 브랜드 컬러로 사용한다.
Dark/Main(구 Deep Pine) — #034443
제목, 강한 대비, Dark Background 등 무게감이 필요한 요소에 사용한다.
Secondary(구 Sea Teal) — #349887
데이터 및 핵심 정보의 강조색으로 사용한다.
Light(구 Mint) — #AFE2E3
보조 데이터, 영역 구분 및 상대적으로 약한 강조에 사용한다.
### Secondary / Neutral Colors
Ocean Blue — #1A6A8C
Moss — #6E9B3F
Flame Amber — #C8801F
Ink — #162B1F
Slate — #5A6664
Gray — #8C9694
Line — #E1E7E5
Mist — #F3F6F5
### Color Usage
기본 사용 색상은 Main Color 계열(Primary Colors: Cosolus Teal/Deep Pine/Sea Teal/Mint) + Black/Dark(Ink) + Gray(Gray, Slate)로 제한한다.
일반 제목·본문·일반 수치는 Black/Dark(Ink 등)를 사용한다.
COSOLUS/자사 및 핵심 강조 요소는 Main Color 계열(Primary Colors)을 우선 사용한다.
Gray(Gray, Slate)는 기존(Existing) 방식, 경쟁/비교 대상, 비활성·보조 정보를 표현할 때 사용한다.
Red/Blue는 명확한 의미가 필요한 예외적인 경우에만 제한적으로 사용한다.
Orange/Amber(Flame Amber) 및 기타 Secondary Color는 일반 Text, 제목, KPI, 핵심 수치 강조에 사용하지 않는다.
Secondary Color(Ocean Blue, Moss, Flame Amber 등)는 Claude_PPT_Design_System.md에서 용도가 명시적으로 정의된 경우에만 사용한다.
강조 우선순위는 Font Weight를 먼저 적용하고, 그다음 Main Color를 사용한다(Font Weight → Main Color).
시각적 다양성 확보만을 목적으로 한 임의의 색상 사용을 금지한다.
한 슬라이드에 불필요하게 많은 색상을 혼용하지 않는다.
## 6. 전체 디자인 분위기
전체 디자인은 기술 기반 소재·화학 기업의 전문성, 신뢰성 및 정돈된 이미지를 전달해야 한다.
기본적으로 White 또는 밝은 Neutral Background + Teal 계열의 조합을 사용한다.
표지, Section Divider 등 강한 전환이 필요한 슬라이드는 Deep Pine / Cosolus Teal 계열의 Dark Background를 사용할 수 있다.
충분한 여백을 확보하고 장식 요소를 과도하게 사용하지 않는다.
색상과 그래픽은 콘텐츠보다 시각적으로 우선하지 않도록 한다.
동일한 역할의 요소에는 PPT 전체에서 일관된 색상 체계를 적용한다.
## 7. 회사 로고 및 Motto
모든 슬라이드에는 등록된 COSOLUS 공식 로고 이미지를 우선 사용한다. COSOLUS 로고를 텍스트로 임의 재현하거나 새로 생성하지 않는다.
로고의 비율, 형태, 색상을 임의로 변형하거나 왜곡하지 않는다.
로고 파일(등록됨, `/docs/brand-assets/CI/`):
- Color(일반/밝은 배경용): `cosolus CI_2.png`
- White/Reversed(다크 배경용, 예: 표지): `cosolus CI.png`
로고의 구체적인 크기와 배치 위치는 적용되는 디자인/Layout MD 또는 아래 “9. 공통 Header System” 규칙에서 정의한다. 해당 기준이 없는 경우에만 전체 슬라이드와의 시각적 균형을 고려하여 판단한다.
회사 Motto인 “COSOLUS, small actions, BIG DIFFERENCE”를 회사 브랜드 요소로 사용할 수 있도록 한다. Motto는 표지, Section Divider, Closing 또는 브랜드 메시지 강조가 필요한 페이지에서 활용할 수 있으며, 모든 페이지에 반복하여 콘텐츠를 방해하지 않도록 한다.
별도의 짧은 태그라인 “We promise tomorrow”는 위 Motto와 구분되는 공통 Header System 요소다. 아래 “9. 공통 Header System” 규칙에 따라 표지를 제외한 모든 슬라이드에 고정 반복 배치하며, 이 반복 배치는 Motto 반복 제한 규정의 예외로 취급한다.
## 8. 기본 디자인 품질
텍스트, 이미지 및 도형 간 의도하지 않은 겹침을 허용하지 않는다.
슬라이드 영역 밖으로 요소가 잘리지 않도록 한다.
텍스트가 텍스트 박스 영역을 초과하지 않도록 한다.
이미지 및 로고의 가로·세로 비율을 왜곡하지 않는다.

## 9. 공통 Header System (표지 제외 모든 슬라이드)
표지를 제외한 모든 일반 콘텐츠 슬라이드는 아래 6개 요소(Section Label, Main Title, 좌측 상단 CI, 우측 상단 Sub Message, 상단 구분선, 우측 하단 페이지 번호)를 콘텐츠 레이아웃 변화와 무관하게 동일한 위치·크기·스타일로 유지하는 공통 고정 Header System으로 취급한다. 아래 각 요소의 위치·크기·색상·표기 형식은 권장 사항이 아니라 반드시 준수해야 하는 Hard Rule이며, 개별 디자인/Layout MD 및 Claude_PPT_Design_System.md보다 우선 적용한다.

> **좌표 기준**: 16:9, **1280×720px** 캔버스(웹PPT 생성기 표준 템플릿 `web-ppt-generator/scripts/templates/style.css` 및 기존 프로젝트 전체와 동일 — `Claude_PPT_Design_System.md` §5의 "1920×1080px 상당" 표기는 EMU 환산 참고용 문구일 뿐 실제 생성 캔버스가 아니므로 좌표 기준으로 사용하지 않는다) 기준 절대 좌표(X, Y는 좌상단 원점 기준 좌측/상단 여백). 1280×720px는 13.333×7.5in 슬라이드를 96dpi로 렌더링한 값과 정확히 일치하므로, 폰트 크기의 pt→px 환산은 **1pt = 1.3333px(96dpi)** 기준을 그대로 사용한다(별도 스케일 보정 불필요). pptx 변환 시에도 캔버스 대비 동일한 상대 위치·비율을 유지한다.

- **Section Label**: 모든 일반 콘텐츠 슬라이드에서 Main Title 바로 위에 배치한다. 해당 슬라이드가 속한 섹션을 표시하는 용도이며(예: BACKGROUND, COMPANY, TECHNOLOGY, PRODUCT), 영문 대문자로 표기한다. Font: Pretendard Light, **12pt(=16px)**. Color: Gray(`#8C9694`). **X=68px**(Main Title X=64px보다 4px 안쪽). **Y=62px**(상단 구분선 Y=56px + 고정 간격 6px). 모든 일반 슬라이드에서 위치·스타일은 고정하고 텍스트만 콘텐츠에 따라 변경한다.
- **Main Title**: Section Label 바로 아래에 배치한다. Font: Pretendard ExtraBold, **28pt(=37.3px)**. 좌측 정렬, **X=64px**, **Y=83px**(Section Label Y=62px + Section Label 라인 높이 20px + 고정 간격 1px). 모든 일반 슬라이드에서 동일한 X축 시작점과 Y축 기본 위치를 사용한다. 표준 가정은 **1줄**이며, Header Safe Area 경계 자체가 1줄 기준으로 고정되므로 Main Title이 실제로 2줄까지 늘어나는 상황은 지양한다 — 제목을 간결하게 작성해 1줄을 유지하는 것이 원칙이다. 임의로 폰트 크기나 시작 위치를 변경하지 않는다. Header Safe Area 하단 경계는 **Y=135px**로 고정한다(Reference(`benefit-impact.pptx`) 실측: Main Title 1줄·28pt ExtraBold·line-height 1.25 기준 하단 약 129.67px, Content Header 상단 약 134.86px, 간격 약 5.18px — 이 실측값을 근거로 산출한 값이며, 지나치게 밀착되어 보이지 않도록 최소한의 여유를 유지한다).
- **좌측 상단 — CI(로고)**: 등록된 COSOLUS 공식 CI를 고정 배치한다. **X=64px, Y=25px, Height=20px**. Width는 원본 가로세로 비율을 유지해 자동 산출한다(비율 왜곡 금지) — 등록 파일 `cosolus CI_2.png`(179×28px, 비율 약 6.39:1) 기준 Height 20px일 때 참고 Width는 **약 128px**이다. 모든 슬라이드에서 동일한 크기와 위치를 유지한다.
- **우측 상단 — Sub Message**: 문구 "We promise tomorrow"를 고정 배치한다. Font Size: **14pt(=18.7px)**. Color: 고정색 `#478689`(Sub Message 전용 고정 색상 — Brand Palette와 별도로 고정되며, Primary 등 Brand Color가 변경되어도 이 값은 바뀌지 않는다). 우측 정렬, 오른쪽 끝 기준선 **X=1216px**(=1280-64, 좌측 여백 64px과 대칭), **Y=25px**(CI와 동일한 상단 높이). 모든 슬라이드에서 동일한 위치·크기·정렬을 유지하며, 콘텐츠에 따라 임의로 이동하거나 크기를 변경하지 않는다.
- **상단 구분선**: **Y=56px**(위치 고정, 변경 없음). **X=64px ~ X=1216px**(좌우 콘텐츠 여백과 동일한 폭, 길이 **1152px**). 두께: **1px**. Color: 고정색 `#478689`(Sub Message와 동일한 값 — Brand Palette와 별도로 고정되며, Primary 등 Brand Color가 변경되어도 이 값은 바뀌지 않는다). 모든 슬라이드에서 동일하게 유지한다.
- **우측 하단 — 페이지 번호**: 현재 페이지 번호만 "1", "2", "3"과 같은 단독 숫자 형식으로 표시한다. "1/20", "2/20" 등 전체 페이지 수를 병기하는 형식은 사용하지 않는다. Font: Pretendard Light, **12px**(기존 결과물 실측값 그대로 고정 — 다른 Header 요소처럼 pt 기준으로 새로 정의하지 않는다). Color: Gray(`#8C9694`). 우측 정렬, 오른쪽 끝 기준선 **X=1216px**(=1280-64, Sub Message와 동일한 우측 기준선). 하단 기준선(텍스트 박스 하단) **Y=692px**(=720-28). 모든 슬라이드에서 동일한 위치·크기·색상·정렬을 유지하며, 콘텐츠에 따라 임의로 이동하거나 크기를 변경하지 않는다. 구현 시 CSS class 이름을 `.deck-page`로 통일한다 — 이 class 하나가 위 X/Y/Font/Color 값의 Single Source of Truth이며, 향후 값이 바뀌면 이 class 정의만 수정해 전체 슬라이드에 일괄 적용한다. 개별 디자인/Layout MD나 Skill 문서에 이 좌표를 별도로 복사해 적지 않는다(2026-08-27 실측 확정 — 실측 대상: `output/2026-battery-outlook-field-test/web_ppt/v1`).

**우측 하단 페이지 번호 옆 — Deck Footnote(Footer, 조건부 Hard Rule)**: 특정 슬라이드가 전체 페이지 공통 출처(예: "자료: ...")를 표시해야 하는 경우에만 사용하는 요소다(위 6개 필수 Header 요소와 달리 사용 여부는 슬라이드별 콘텐츠에 따라 선택적이나, **사용하는 경우** 아래 위치·크기는 고정 Hard Rule이다) — "11. Vertical Content Divider"와 동일하게 조건부 Hard Rule로 취급한다. 페이지 번호와 같은 하단 Row를 공유하되 페이지 번호 영역을 침범하지 않도록 우측을 비워 둔다: 좌측 정렬 **X=64px**, 우측 경계 **X=1152px**(=1280-128, 페이지 번호 기준선 X=1216px로부터 64px 여유 확보), **W=1088px**. 하단 기준선(텍스트 박스 하단) **Y=692px**(=720-28, 페이지 번호와 동일한 하단 기준선 — 같은 Row로 시각적으로 정렬됨). 허용 Y 범위: **Y=678~692px**(상단 Y=678px는 아래 Bottom Safe Area 경계와 동일). Font: Pretendard Regular, **11px**. Color: Gray(`#8C9694`). 구현 시 CSS class 이름을 `.deck-footnote`로 통일한다 — 이 class 하나가 위 X/Y/W/Font/Color 값의 Single Source of Truth이며, 개별 디자인/Layout MD나 Skill 문서에 이 좌표를 별도로 복사해 적지 않는다. 표/카드 등 특정 콘텐츠 하나에만 속하는 각주는 이 요소가 아니다 — 그런 각주는 아래 "본문 Content" 취급을 그대로 따르며 별도 클래스(예: `.content-footnote`)로 구현한다(2026-08-27 역할 분리 확정 — 실측 대상과 동일 프로젝트: `output/2026-battery-outlook-field-test/web_ppt/v1`).

표지는 페이지 번호를 표시하지 않는다(표지 구성은 별도 Slide-Type Rule을 따른다).
본문 콘텐츠가 위 6개 요소의 영역(특히 Header Safe Area 하단 경계 Y=135px 이상 구간)을 침범하지 않도록 안전영역(safe area)을 확보한다.
**Bottom Safe Area 하단 경계는 Y=678px로 고정한다**(위 페이지 번호 텍스트 상단 실측값과 정확히 일치 — 페이지 번호가 차지하는 우측 하단 영역과 겹치지 않도록 하는 하한선). 표지를 제외한 모든 슬라이드에서 본문 Content(텍스트·이미지·도형 등 실제 콘텐츠 요소, 표/카드 전용 `.content-footnote` 포함)의 하단 경계는 Y=678px를 넘지 않아야 한다. 페이지 번호 자체의 영역(X=1216px 우측 기준선, Y=678~692px)과 위 Deck Footnote 영역(X=64~1152px, Y=678~692px)은 이 Bottom Safe Area 판정에서 제외되는 별도의 고정 Footer 영역이다.
위에 명시되지 않은 세부 사항은 전체 슬라이드와의 시각적 균형을 고려하여 판단하되, 위에 명시된 위치·크기·색상·표기 형식 기준과 충돌해서는 안 된다. 페이지 번호·Deck Footnote 위치와 Bottom Safe Area는 더 이상 이 판단 대상이 아니다(위에서 고정값으로 정의됨).

## 10. Content Region Header (Content Comparison Header 포함)
Content Region Header는 본문이 2개 이상의 병렬 Content Region으로 나뉘고, 각 Region이 서로 다른 독립 주제를 가지는 경우(각 Region에 독립적인 이름을 붙일 수 있고 각각 별도의 내용을 담는 경우) 기본적으로 사용한다 — 2-Column, 3-Column, 동등 병렬 카드 구조가 대표 사례다. 사진+설명, 그래프+해설처럼 하나의 메시지를 표현하기 위해 역할만 분리한 구조(예: `visual-insight.md`)에는 Header를 강제하지 않는다. 이 원칙을 실제 콘텐츠에 어떻게 적용할지 — Header의 사용 여부·개수·위치·어떤 Content Region에 대응하는지 — 는 각 디자인/Layout MD가 정의한다.

Before/After, Existing/Improved, Current/COSOLUS 등 두 대상을 비교하는 Content Comparison 계열 Layout(예: `before-after.md`)뿐 아니라, Three-Column처럼 대등하고 독립적인 N개 Column이 각자 상단 Header(대상·주제 라벨)를 사용하는 병렬 구조 Layout(예: `three-column.md`)에서도, 각 Column 상단 Header Bar에는 아래 스타일을 Hard Rule로 고정한다. 개별 Layout Reference나 Design System은 Height·Font·Color·Padding·Corner·Fill·Divider·Gap 등 Header Bar 자체의 시각 스펙을 임의로 새로 만들지 않는다 — 개별 Layout MD가 결정하는 것은 Header의 개수·폭·Content Group 대응 관계, 그리고 아래 두 Named Variant 중 어느 것을 사용할지뿐이다.

**공통 Header 스타일(모든 Variant 동일)**: **Height=0.561in**(96dpi 환산 약 54px). Font: Pretendard SemiBold, **Font Size=20pt**(96dpi 환산 약 26.7px). Font Color: **#0F1E1F**. Letter Spacing: **-0.3pt**(약 -0.4px). Text Alignment: 중앙 정렬(Center). Text Box 내부 여백(Padding): **0**. Rounded Corner 사용 금지(모서리 직각, Sharp Corner). 한 슬라이드 안의 모든 Header Bar는 높이·Typography·정렬 구조를 동일하게 유지한다. Header의 폭과 위치는 적용되는 Layout Reference(예: Column 구조)에 따라 결정한다.

**Parallel Variant**(대등하고 독립적인 N개 병렬 Region의 기본값): Background: **#F4FAFA**. 상단 Divider: **#067875, 0.75pt**. 하단 Divider: **#067875, 0.5pt**.

**Contrast Variant**(Before/Existing/Current ↔ After/Improved/COSOLUS처럼 의미적으로 명확한 대립 구조 전용): Before/Existing/Current 측 — Background Fill 없음(투명), 상단 Divider **0.75pt**·하단 Divider **0.5pt**, 색상은 위 5번 항목의 Neutral 팔레트 중 Line(`#E1E7E5`). After/Improved/COSOLUS 측 — Background **#F4FAFA**, 상단 Divider **#067875, 0.75pt**, 하단 Divider **#067875, 0.5pt**.

Three-Column처럼 **대등하고 독립적인 N개 병렬 항목**을 나열하는 Layout, 또는 하나의 Header를 Gap을 두고 여러 Bar로 분할해 사용하는 Layout(예: `benefit-impact.md`의 분할 Header)은 **Parallel Variant**를 모든 Header Bar에 동일하게 적용한다 — 같은 슬라이드 안에서 Variant를 섞어 쓰지 않는다. Before/After처럼 **서로 대립하는 두 대상을 비교**하는 Layout은 **Contrast Variant**를 사용해 대비를 표현한다. 콘텐츠·톤상 명확한 이유가 있어 Contrast Variant의 Fill 없는 쪽을 병렬 Header에 적용해야 하는 경우에도 3개 이상 모든 Header Bar에 예외 없이 동일하게 적용해야 한다.

**Header Gap**: 2개 이상의 독립 Header Bar를 사용하는 경우, Bar끼리 맞닿아 하나의 통합 Header처럼 보이지 않도록 Bar 사이에 시각적으로 구분되는 Gap을 반드시 확보해야 한다(Hard Rule) — Gap 없이 맞닿은 Bar 사이에 선(Divider 등)만 그어 분할된 것처럼 표현하는 방식은 허용하지 않는다. Gap의 시각적 일관성은 이 Hard Rule이 관리하는 범위다 — 동일 슬라이드 내 병렬 Header Bar 간 Gap은 서로 동일하게 유지하고, 해당 Content Region의 Grid·정렬 기준에 맞춰 자연스럽게 배치한다. 개별 Layout MD는 서로 다른 고정 %/px Gap 값을 각자 정의하지 않으며, 이 Hard Rule도 이를 대체하는 새로운 고정 %/px 수치를 별도로 강제하지 않는다 — "동일 Gap 유지 + Content Region Grid 기준 자연 배치"라는 원칙만 공통으로 적용한다.

이 Header 규칙은 Layout이 Column/Content Group 상단에 Header Bar를 사용하기로 선택한 경우에만 적용되며, Header 자체의 사용 여부·개수·폭·대응 관계는 각 Layout Reference의 규칙을 따른다. 여러 비교 대상을 N개 Column/Row 격자로 나열하는 Table의 Header는 이 조항이 아니라 "10B. Table Header Row"를 따른다.

## 10B. Table Header Row (N-Column Data Table)
Comparison Matrix, Table Comparison처럼 여러 비교 대상을 격자형 Table 구조로 나열하는 Layout의 Header Row는 위 "10. Content Region Header"(2~3개 병렬 Content Region이 각자 갖는 독립 Header Bar)와는 다른 별도 컴포넌트다. Table Header Row의 색상·Typography·Table Grid Divider 등 시각 스펙은 이 Hard Rule에서 정의하며, 개별 Layout MD는 Column/Row 구조, Header 사용 여부, 비교 대상(축) 배치 등 구조적 판단만 정의한다.

**Header Row**: Column/대상 개수와 무관하게 Header Row 전체를 **Company Main Color 계열(Primary, `#067875`) Fill + White Bold Text**로 통일한다. Header Row를 Column/대상 단위로 나눠 일부만 Fill하거나 다른 스타일을 섞어 쓰지 않는다. Header Row 텍스트는 가로·세로 모두 Center Align을 기본으로 한다.

**Body Row**: White 배경 + Ink(`#162B1F`) 계열 텍스트.

**Table Grid(Cell Divider)**: 얇은 직선(1px 내외)만 사용한다. Rounded Corner, Card 그림자, Cell 간 간격을 띄운 카드형 표 재해석을 사용하지 않는다. 색상은 Line(`#E1E7E5`)을 기본으로 한다. Table Grid는 "11. Vertical Content Divider"가 아니라 이 조항이 관리하는 별도 규칙이다 — 두 Divider 체계를 섞어 쓰지 않는다.

**Typography**: Header Row Label / Criteria Column Label **14pt SemiBold**, Body/Data Cell **16pt**(Regular~Light), Cell 설명 캡션 **14pt**(강조 Cell만 SemiBold), Footnote **14pt Light**. 이 값은 `Claude_PPT_Design_System.md` §3 Typography Tier(Caption/Auxiliary 14pt, Body 16pt)와 이미 일치하며 서로 상충하지 않는다 — Layout MD가 공통 Table Typography를 적용할 때 이 Hard Rule 기준과 Design System §3 최소 기준이 서로 다르게 해석되는 경우 이 Hard Rule을 우선한다.

**강조(자사/핵심 대상) 기본값**: Body Fill이 아니라 Main Color(Primary) **Text + Bold**로 표현하며, Row/Column 전체 배경 Fill로 강조를 고정하지 않는다. 강조는 최대 1개 Column(또는 1개 Row)까지만 적용한다.

**Layout-specific Emphasis 예외**: 위 강조 기본값은 일반 Table에 적용하는 공통 기준이다. 이 Hard Rule은 모든 Table을 동일하게 만드는 규칙이 아니라 공통 기준을 관리하는 규칙이며, Layout 고유의 명확한 강조 목적을 대체하지 않는다 — 특정 Layout이 "자사와 경쟁사를 비교해 경쟁우위를 명확히 시각적으로 대비시키는 것"처럼 뚜렷한 목적을 가진 경우, 해당 Layout MD는 이 기본 강조 규칙과 다른 고유 강조 Variant(예: 자사 Column 전체 Solid Fill 강조)를 별도로 정의해 사용할 수 있다. 이러한 예외는 해당 Layout MD 안에 "이 Layout만의 고유 강조 방식"으로 명시적으로 표시해야 하며, 이 경우에도 Header Row/Body Row/Table Grid 등 나머지 Table 스펙(위 항목들)은 그대로 따른다. 강조 색상 값 자체는 이 Hard Rule 또는 "5. Brand Color"의 기존 Brand Token만 참조하며, 각 Layout MD가 리터럴 HEX 값을 별도로 작성하지 않는다.

**Reference 예외**: Reference PPT가 제공된 경우, 위 기본 Header/강조 방식보다 Reference가 실제로 사용한 방식을 우선 적용할 수 있다.

## 11. Vertical Content Divider (Conditional Hard Rule)
콘텐츠 영역을 2개 이상으로 분할하면서 영역 간 구분을 위한 세로 Divider가 필요한 경우, 아래 디자인을 Hard Rule로 고정한다. 개별 Layout Reference나 Design System은 이와 다른 Divider 색상·두께·스타일을 임의로 새로 만들지 않는다.

**디자인(Solid, 기본값)**: Width **0.5pt**. Line: Solid. 중앙 핵심색: **#034443**. Gradient 방향: Vertical(수직). 중앙부가 가장 진하고 상·하단으로 갈수록 자연스럽게 Fade-out되며, Gradient 중심점은 약 **53%** 지점이다. 양 끝은 배경 White에 자연스럽게 사라지도록 처리한다.

**Dashed Variant**: 병렬 Content Region 사이의 경계는 항상 위 Solid를 사용한다. Process Group처럼 하나의 Content Region 내부에서 의미상 하위 그룹을 구분해야 하는 경우에 한해 Dashed Variant를 허용한다(예: `process-comparison.md`의 Phase/Group 경계). Dashed Variant도 두께·색상은 Solid와 동일하게 유지한다 — 이 Hard Rule은 구체적인 dash 길이/간격(px pattern)을 별도로 강제하지 않으며, Solid와 동일한 두께·색상 기준 안에서 자연스러운 dash 표현을 사용한다.

**적용 범위**: Divider는 실제로 구분하려는 Content Region의 범위(시작~끝) 안에서만 표시하며 그 범위를 벗어나 연장하지 않는다. Header 영역(공통 Header System, "9. 공통 Header System" 참조) 및 사용 중인 경우의 Main Title Supporting Message 영역("12. Main Title Supporting Message" 참조)까지는 침범하지 않는다 — Divider는 Main Title이나 상위 Header 영역까지 연장하지 않는다. Divider의 시작과 끝은 인접 콘텐츠(Header Bar, Key Message, 상하단 텍스트 등)에 바로 닿지 않는 자연스러운 최소 여백을 확보한다 — 이 여백은 고정된 %/px 수치가 아니라, 실제 Content Region의 콘텐츠 배치(시작~끝 범위)를 기준으로 매번 판단한다. 개별 Layout MD는 8%, 10~15% 같은 서로 다른 고정 Inset 수치를 정의하지 않으며, 이 Hard Rule도 이를 대체하는 새로운 고정 수치를 강제하지 않는다.

**Table Grid와의 구분**: Table(격자형 다중 비교) 내부의 Row/Column 구분선은 이 조항이 아니라 "10B. Table Header Row"의 Table Grid 규칙을 따른다 — 두 Divider 체계를 섞어 쓰지 않는다.

이 Divider 규칙은 콘텐츠 영역 분할 시 세로 Divider를 사용하기로 선택한 경우에만 적용되며, Divider 자체의 사용 여부는 각 Layout Reference의 규칙을 따른다.

## 12. Main Title Supporting Message (표지 제외 기본 적용, 예외 허용)
표지를 제외한 일반 콘텐츠 슬라이드는 **기본적으로** Main Title 아래·Main Content 위에 해당 슬라이드의 핵심 내용을 설명하는 1~2줄의 Supporting Message를 배치한다(2026-08-19 확정 — 기존 "필요할 때만 사용하는 Optional 요소"에서 변경). 이는 특정 디자인/Layout MD나 특정 Column 구조에 종속되지 않는 슬라이드 전체 공통 요소이며, 개별 Layout MD는 아래 위치·위계 규칙을 임의로 새로 만들지 않는다.

**사용 조건(기본 적용 + 예외)**: 원본 콘텐츠(`material_analysis.json`/`slide_outline.md`)에 근거한 핵심 설명만 사용하며, 자료에 없는 새로운 주장·수치를 만들어내지 않는다. 다음 경우는 예외로 생략할 수 있다 — ① 표지, ② 내용상 Supporting Message가 실질적으로 불필요하거나(제목 자체가 이미 슬라이드 내용을 충분히 설명), ③ 근거 콘텐츠가 없어 억지로 문장을 만들어야 하는 경우. 예외에 해당하지 않는데 형식을 맞추기 위해 내용 없는 빈 Supporting Message를 만들지는 않는다 — "9. 공통 Header System"의 6개 필수 요소처럼 항상 존재를 강제하는 요소는 아니다.

**위치**: "9. 공통 Header System"에서 정의하는 Main Title 바로 아래, Main Content(본문 영역) 시작 위치보다 위에 배치한다. Header Safe Area 하단 경계(§9, Y=135px)는 Supporting Message가 없는 슬라이드 기준값이며, Supporting Message가 있는 슬라이드는 그 아래로 Safe Area가 확장된다.

**분량**: 1~2줄 이내로 간결하게 작성한다. 설명이 그보다 길어지는 경우 Supporting Message에 욱여넣지 않고 Main Content 내 Supporting Text/Evidence 영역에서 다룬다.

**정보 위계 및 크기**: Main Title보다 낮고 일반 Body Text보다 높은 위계를 갖는다. Font Size는 별도로 새로 정의하지 않고 `Claude_PPT_Design_System.md` §3 Typography 체계 중 이 위계(Main Title 미만·Body 이상)에 해당하는 기존 크기(Content Header 레벨, 20pt)를 사용한다(2026-08-19 확정 — 기존 Explanation 레벨 18pt 참조에서 변경). Font Weight는 Main Title(ExtraBold)과 구분되는 낮은 강조 수준을 사용하고, Color는 위 "5. Brand Color" Color Usage 원칙(일반 제목·본문은 Black/Dark 계열)을 따른다.

**Content Start Y 조정**: Supporting Message가 추가되는 경우, Main Content 내 특정 요소만 개별적으로 아래로 이동시키지 않는다 — Supporting Message의 높이와 간격만큼 Main Content 전체의 시작 위치(Content Start Y)를 함께 아래로 조정한다. 이 조정은 Supporting Message를 사용하는 해당 슬라이드에만 적용되는 상대 조정이며, 모든 슬라이드의 Content Start Y를 하나의 고정값으로 통일하는 규칙이 아니다 — Supporting Message가 없는 슬라이드는 기존 Content Start Y를 그대로 유지한다.

**세부 값**: Main Title–Supporting Message 간, Supporting Message–Main Content 간 정확한 Gap(px) 등 세부 수치는 이 Hard Rule에서 고정하지 않으며, `Claude_PPT_Design_System.md`의 Content Density/Parallel Layout Alignment 원칙을 참고해 각 디자인/Layout MD 또는 개별 슬라이드 판단에 따른다.

이 규칙은 위 "사용 조건"의 예외(①②③)에 해당하지 않는 모든 일반 콘텐츠 슬라이드에 기본 적용된다. Supporting Message를 사용하는 슬라이드는 아래 "Content Start Y 조정" 원칙에 따라 `.body-box.with-support`(Hard Rule §9 기본값 대신 확장된 Safe Area) 구조를 사용한다.

본 Hard Rule은 개별 디자인/Layout MD보다 우선 적용한다.
개별 디자인/Layout MD와 본 Hard Rule이 충돌할 경우 Hard Rule을 우선한다.
Header/Table Header Row/Divider 등 공통 컴포넌트는 이 Hard Rule이 "어떻게 보여야 하는지"(색상·높이·Typography·Padding·Gap·두께·기본 스타일 등)를 정의하고, 각 디자인/Layout MD는 "어디에·몇 개·어떤 의미로 필요한지"(사용 여부·개수·위치·구조적 의도)를 정의한다 — 개별 Layout MD는 전자(디자인 값)를 임의로 재정의하지 않는다. 단, Layout 고유의 명확한 시각적 강조 목적(예: 자사 강조, Before/After 대비, 핵심 수치 강조)을 위한 Variant는 "10B. Table Header Row"의 Layout-specific Emphasis 예외처럼 각 조항이 명시적으로 허용하는 범위 안에서 유지된다.
구체적인 레이아웃, 요소 배치, 이미지 구성, 카드 구조, 정보 시각화 방식 등은 개별 디자인/Layout MD에서 정의한다.
어떤 Layout을 선택할지는 입력된 콘텐츠와 PPT의 목적을 기준으로 Prompt 또는 PPT 제작 Agent가 판단한다.
추가로 반드시 고정할 요소가 생기면 테스트 및 협의 후 본 문서에 추가한다.
