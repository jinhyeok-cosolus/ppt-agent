# Comparison Matrix Layout Reference — 통합됨

> **2026-10-14부터 독립 Layout이 아니다.** Comparison Matrix는
> [`table-comparison.md`](table-comparison.md)의 **Visual Evidence 구성**
> (§7)으로 통합되었다. 이 파일은 기존 문서·`slide_outline.md`의 링크가
> 깨지지 않도록 안내문으로만 남긴다.

- 여러 대상을 같은 기준으로 비교하는 표는 모두 `table-comparison.md`를
  쓴다. 구성(기본 / Visual Evidence)과 강조(없음 / Text / Outline / Solid
  Card)는 그 문서 §7·§8에서 고른다.
- 기존 이 문서의 고유 기능 — Visual Evidence의 대상×기준 Cell 귀속,
  Evidence Row를 Header 바로 아래 배치, 동일 크기 Image Frame, 연속 Column
  Group 강조와 상단 Label — 은 `table-comparison.md` §7·§8과 Hard Rule
  §10B로 옮겨졌다.
- 다른 Layout MD가 "비교 대상이 3개 이상이면 `comparison-matrix.md`"라고
  안내하는 경우 `table-comparison.md`로 읽는다.
