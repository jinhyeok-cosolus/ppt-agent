# Company Introduction (기업개요)

## Purpose
회사의 정체성, 핵심 메시지 및 기본 정보를 외부 고객이 빠르게 이해할 수 있도록 전달하는 기업개요 슬라이드.

> **Status: 확정(구조 고정형, 2026-10-12)**. 디자인 기준은 COSOLUS IR 레퍼런스
> `docs/brand-assets/기업개요 Reference.pptx`의 도형 실측값이다. 아래 구조·좌표·Typography·
> 구분선 스타일은 프로젝트마다 바꾸지 않으며, **핵심 메시지 문구, Company Facts 항목(최대 5행),
> 우측 사진 파일**만 콘텐츠에 맞게 교체한다. 구현은 골격
> `web-ppt-generator/scripts/templates/components/company-overview.css`/`.html`을 그대로 복사해
> 교체 가능 영역(`{}`)만 채운다.

## 공통 Header와 기업개요 전용 예외
- CI·Section Label·Main Title·Sub Message·상단 구분선·좌측 Brand Line의 **위치·크기는 일반 본문과 동일**하게 Hard Rule §9를 그대로 따른다(기업개요 전용 위치 예외 없음). Main Title은 `기업소개`(또는 자료의 동일 의미 제목)를 사용한다.
- 기업개요 전용 예외는 Hard Rule §9 "슬라이드 유형별 적용 범위" 표에 정의된 것만 적용한다:
  - Sub Message 글자색만 White(`#FFFFFF`) — 우측 사진 위에 놓이기 때문
  - Section Label 표기·색만 레퍼런스 그대로 — `Company`(대문자 변환 없음), `#808080` 불투명도 70%
  - 상단 구분선 색상만 `#96A4A5`, 우측 사진보다 위 레이어로 그려 사진 영역에서도 보이게 함
  - 우측 하단 페이지 번호 미표시
- Hard Rule §12 Main Title Supporting Message는 사용하지 않는다 — 아래 고정 "핵심 메시지" 영역이 그 역할을 대신한다(§12 예외 ④).
- 기업개요 전용 색(White Sub Message, `#96A4A5` 구분선, `#073E41` 핵심 메시지)은 이 슬라이드에서만 쓰며 다른 Layout에 적용하지 않는다.

## Layout (1280×720px, 레퍼런스 실측 — 고정)
| 영역 | 위치·크기 | 스타일 |
|---|---|---|
| 우측 사진 패널 | X=963~1280, Y=0~720(전체 높이, 우측 끝까지 Full-Bleed) | 높이에 맞춰 채우고 좌우만 Crop(레퍼런스 Crop 좌 17%·우 14% → 가로 위치 약 55%). 흑백 톤, **투명도 60%**(레퍼런스 그림 효과 그대로 — 흰 배경 위의 연한 배경 사진) |
| 핵심 메시지 | 텍스트 박스 X=41.6~927.3(폭 885.7), 상단 Y=139.8, 내부 여백 좌우 9.6·상하 4.8 | Pretendard ExtraBold **28pt**, Color **`#073E41`**, letter-spacing -0.2pt, **가운데 정렬**, 1~2줄 |
| Company Facts | X=62.1, Y=257.5, 폭 852.7. 2열(항목명 154.7 / 정보 값 698.0) × 행 높이 71.1, **최대 5행** | 아래 "Company Facts" 참조 |

- 사진 패널을 제외한 왼쪽 영역은 흰 배경이다. 카드·배경 패널·그림자·둥근 모서리를 추가하지 않는다.
- 핵심 메시지와 Company Facts의 위치·정렬·간격은 콘텐츠 양과 무관하게 고정한다. 콘텐츠가 적어도 영역을 늘리거나 중앙으로 옮기지 않는다.

## Company Facts (기업정보 전용 구조 — 데이터 표가 아님)
- 이 영역은 항목명-값 목록인 **Company Facts 전용 구조**이며, Hard Rule §10B Table Header Row(헤더 행 채움·Body 16pt 등)의 적용 대상이 아니다. 헤더 행을 만들지 않는다.
- **항목명 열**: Pretendard SemiBold **16pt**, Ink, 열 안에서 가운데 정렬. 2~3글자 항목명은 레퍼런스처럼 글자 사이를 고르게 벌려 같은 폭(약 67px)으로 맞춘다(문자열에 공백을 넣지 않고 글자마다 감싸 양끝 정렬 — 골격 HTML 주석 참조).
- **정보 값 열**: Pretendard Light **14pt**, Ink, 좌측 정렬, 세로 가운데 정렬. 한 행 안에서 최대 2줄.
- **행 구분선**: 첫 행 위 0.25pt `#034443`, 나머지 행 사이와 마지막 행 아래 0.25pt `#808080`. 세로선·셀 채움 없음.
- **행 수**: 최대 5행. 5행보다 적으면 위(Y=257.5)에서부터 채우고 남는 아래 공간은 비워 둔다(행 높이를 늘리지 않음). 5행을 넘는 정보는 중요도가 낮은 항목을 빼거나 다른 슬라이드로 옮긴다.
- 권장 항목(제공된 자료에 있는 것만): 기업명, 대표자, 임직원, 소재지, 비전. 자료에 없는 값을 만들지 않는다.

## 우측 사진
- 파일만 교체할 수 있고 영역·Crop 방식은 고정이다(높이 채움 + 좌우 Crop, `object-fit: cover`). 의도된 프레임 Crop이므로 `data-visual-frame="panel"`을 붙인다 — QA는 이 표시가 있는 사진의 Crop을 오류가 아닌 참고 기록으로 처리한다.
- 투명도 60%는 골격 CSS(`opacity: 0.6`)가 적용하며 pptx 변환 시 그림 투명도(alphaModFix)로 그대로 옮겨진다 — 흰색 오버레이 박스를 따로 얹지 않는다.
- 흑백 톤은 CSS `filter`가 아니라 **흑백 이미지 파일**로 맞춘다(pptx 변환에 CSS 필터가 반영되지 않음). 컬러 사진이면 흑백 사본(`{원본명}-gray.png`, 원본 유지)을 만들어 사용한다.
  예: `python -c "from PIL import Image; Image.open('a.png').convert('L').save('a-gray.png')"`
- 사진 선택 우선순위: ① 사용자가 이번 작업에서 제공한 회사 사진 ② `docs/brand-assets/introduction-images/` 의 회사 사진(기본값: `company-overview-photo.png`, 레퍼런스 사진) — 회사와 무관한 스톡 이미지는 쓰지 않는다. 사람·장비 등 핵심 피사체가 잘리지 않는지 확인하고, 필요하면 가로 위치(object-position)만 조정한다.

## Typography
- Header 요소는 Hard Rule §9를 따른다.
- 핵심 메시지 28pt ExtraBold, 항목명 16pt SemiBold, 정보 값 14pt Light는 레퍼런스 실측값으로 고정한다. 정보가 많다는 이유로 크기를 줄이지 않고 항목·문장을 줄인다(Design System §3 Font Size 적용 원칙).

## Soft Rules
- 핵심 메시지는 회사의 정체성과 사업 방향이 드러나는 1~2줄로 요약하고, 제공된 자료에 근거한 내용만 쓴다. 두 줄이면 의미 단위로 줄을 나눈다.
- Company Facts는 외부 청중에게 필요한 정보만 선별한다.

## Avoid
- 구조·좌표·구분선 스타일 변경, 좌우 영역 반전, 사진 영역 축소
- 회사 기본정보를 긴 문장으로 나열하는 구성
- 정보가 많다는 이유로 글자 크기를 축소하는 것
- Company Facts를 §10B 데이터 표처럼 헤더 행·채움·세로선으로 꾸미는 것
- 카드·그림자·테두리 등 장식 추가, CSS 필터로 사진 톤 처리
- 회사와 관련 없는 스톡 이미지 사용, 이미지 비율 왜곡
