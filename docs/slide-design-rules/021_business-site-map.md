# Business Site Map — Pin + Outside Card

> 사업장(오피스/공장/연구소) 위치를 소개할 때 사용하는 레이아웃. 지역
> 지도 위에 위치를 아이콘 핀으로 표시하고, 지도 바깥쪽에 사진과 주소를
> 담은 카드를 점선으로 연결해 보여준다. 코솔러스-회사소개-덱 프로젝트의
> "BUSINESS SITE" 섹션에서 최초로 적용·확정되었다.

------------------------------------------------------------------------

## 0. 적용 범위

다음 콘텐츠에 우선 적용한다.

-   회사소개/사업장 소개에서 특정 지역(본사, 공장, 연구소 등) 위치를
    보여줘야 하는 경우
-   지도 기반으로 위치를 시각화하되 사진과 주소도 함께 전달해야 하는
    경우

공통 Header, Logo, 기본 폰트, 브랜드 컬러 등은 Hard Rule을 따른다.

------------------------------------------------------------------------

## 1. Layout Identity

핵심 구조:

`Region Map + Pin Marker + Single-bend Dashed Connector + Outside Card(Photo + Address)`

``` text
┌───────────────┐
│               │●─┐
│   Region Map  │  │
│   (Zoom-in)   │  ┊(dashed, single bend)
│               │  │
└───────────────┘  ▼
                ┌─────────────────────┐
                │ [Photo]  전주 (본사)  │
                │          전북 전주... │
                └─────────────────────┘
```

------------------------------------------------------------------------

## 2. Base Map

-   국가 전체 지도에서 해당 광역 지역을 원형 점선으로 표시하고, 그
    지역을 확대(Zoom-in)한 세부 지도를 함께 보여주는 2단 구성을
    기본으로 한다(등록 자산 `docs/brand-assets/introduction-images/location.png`
    참고).
-   확대 지도의 하위 행정구역은 얇은 White Line으로 구분하고, 전체
    영역은 Cosolus Teal 단색으로 채운다.
-   지도 자체에 그림자, 그라디언트, 3D 효과를 사용하지 않는다.
-   동일한 베이스 지도 자산은 여러 프로젝트에서 재사용한다. 매번 새로
    그리지 않는다.

------------------------------------------------------------------------

## 3. Pin Marker

-   실제 사업장 위치는 지도 이미지 내 임의의 위치가 아니라, 가능하면
    실제 좌표(위도/경도)를 지도 이미지의 픽셀 좌표 또는 비율(%) 좌표로
    환산해 배치한다.
-   사용자가 정확한 좌표를 제공하지 않은 경우, "개략적인" 위치라는
    점을 전제로 지도상 해당 지역의 육안 위치에 합리적으로 배치할 수
    있다. 단, 실제와 크게 어긋나 보이는 배치는 피한다.
-   Pin 스타일: 작은 원형 Dot(Sea Teal 채우기) + 흰색 테두리 + 얇은
    Mint 외곽 링. 화살표형 핀, 3D 핀 아이콘은 사용하지 않는다.
-   동일 슬라이드에 여러 Pin이 있는 경우 모두 동일한 크기·스타일을
    유지한다.

------------------------------------------------------------------------

## 4. Connector Line

-   Pin과 카드는 점선(Dashed, Mint 계열)으로 연결한다.
-   기본형은 **단일 절곡(단 한 번만 꺾이는 'ㄴ'자 형태)** 을 우선한다.
    Pin에서 아래로 내려간 뒤 카드 쪽으로 한 번만 꺾어 연결한다.
-   지도 위쪽이나 바깥으로 크게 돌아가는 경로, 여러 번 꺾이는 경로는
    공간이 실제로 부족한 경우가 아니면 사용하지 않는다 — 불필요하게
    복잡한 연결선은 지도보다 시각적으로 우선하지 않는다.
-   화살표 머리는 사용하지 않는다.

------------------------------------------------------------------------

## 5. Outside Card (Photo + Address)

-   카드는 지도 바깥쪽에 독립적으로 배치하며, 다음 정보를 포함한다.
    1.  사업장 사진(정사각형 또는 유사 비율 썸네일)
    2.  사업장명 (예: "전주 (본사)")
    3.  주소
-   카드 모서리는 둥글게(약 12px) 처리하고, 옅은 Shadow와 Line 색
    테두리로 지도/배경과 구분한다.
-   사진이 아직 준비되지 않은 경우, 실제 사진처럼 보이는 임의의
    이미지를 생성하지 않는다. 빈 Placeholder 박스(연한 배경 + "사진"
    등 짧은 라벨)로 대체하고, 실제 사진 파일이 제공되면 동일 경로에
    교체하는 방식을 우선한다.

------------------------------------------------------------------------

## 6. Multiple Sites — 확장 시 주의

사업장이 2개 이상으로 늘어나는 경우, 이 문서의 단일 사업장 패턴(Pin 1개
+ Card 1개)을 기계적으로 반복 확장(Pin 여러 개 + Card 여러 개 목록)하기
전에, 슬라이드 밀도와 가독성을 고려해 사용자에게 배치 방향을 먼저
확인한다. 여러 사업장을 한 슬라이드에 표시할 때의 구체적인 규칙은 이
문서에서 아직 확정하지 않았다.

------------------------------------------------------------------------

## 7. Soft Rule

사업장 위치를 사진·주소와 함께 소개해야 하는 경우 이 레이아웃을
우선적인 후보로 검토한다.

핵심 Identity(지역 지도 + Pin + 단일 절곡 점선 + 사진/주소 카드)는
콘텐츠에 따라 세부 크기·간격을 조정하더라도 유지한다.
