## Slide 26 — 단일 분기 골격 (Single-Branch Skeleton)
분기 이후 각 Lane이 더 이상 갈라지지 않는 가장 단순한 인스턴스. **재분기가 없는 Flow Diagram(예: COSOLUS Slide 16 — 블랙매스 → 양극재용/음극재용 2개 Lane, Lane 내부 재분기 없음)의 1차 대응 참조**다.

**실측상 확인되는 구조 사실**:
- Branch Point는 두 Lane의 Y좌표(45.11%/82.83%)를 정확히 잇는 **하나의 수직 직선**이며, 그 위/아래 끝에서 바로 수평 화살표가 이어진다 — 곡선(Bezier 등)으로 분기를 표현한 도형은 이 인스턴스에 존재하지 않는다.
- Trunk/Lane 연결선은 각각 **2개의 짧은 세그먼트 + 그 사이 빈 간격**으로 구성된다. 이 간격은 도형이 아니라 여백이며, 실제 콘텐츠(Material/Process 라벨이나 도형)가 들어갈 자리로 비워둔 것으로 관찰된다.
- Lane당 Node 자리는 **정확히 1개**(세그먼트1↔세그먼트2 사이)만 실측된다 — Slide 16처럼 한 Lane에 Process가 2개(건식환원, 부유선별) 이어져야 하는 경우는 이 골격이 직접 보여주지 않는 확장 사례다. 이때는 세그먼트를 Node 개수만큼 반복해 이어붙이되, "Connector는 Node 앞뒤에서만 끊긴다"는 이 골격의 원칙은 그대로 유지한다(개별 Node 폭·간격의 새 비율을 이 문서가 대신 정하지 않는다 — 실측된 세그먼트 2 하나의 간격(Lane A 17.87%p, Lane B 18.96%p)을 참고 단위로 삼아 콘텐츠 분량에 맞게 균등 배분하는 것은 `content-visualization-freedom.md` 범위의 판단으로 남긴다).
- Lane 세그먼트 2 이후(80.86%/84.97% 지점 이후) 별도 도형이 없다 — Output 자리는 이 골격 밖(Body Box 우측 나머지 영역)에 암묵적으로 남겨진 것으로 관찰된다.

### 2단 분기 Connector 경로 실측 (연결선 12종 전체 역할 분해)
> 아래는 위 표의 "연결선 12종"을 각 도형의 실제 in(l,t,w,h)에서 endpoint 좌표를 직접 계산해 연결 관계(끝점이 서로 근접하는 선끼리)를 추적한 결과다. 추정·보간 없이 각 선분의 실측 시작/끝 좌표만 사용했다. Body Box % 변환은 문서 서두와 동일한 공식(non-support 기준, left=0.667in/top=1.406in/width=12in/height=5.427in)을 그대로 적용했다.

**연결 관계(끝점 근접 매칭으로 추적)**:
- 연결선25(Trunk)의 끝점(18.55, 49.31)과 Y가 정확히 일치하는 지점은 연결선23·연결선26이 맞닿는 X=35.68%, Y≈49.3~49.7% 구간이다. 즉 **1차 Branch Point는 연결선23(위쪽 절반)과 연결선26(아래쪽 절반)이 X=35.68%에서 이어진 하나의 연속 수직선**이며, Trunk(25)는 이 수직선의 중간 높이로 들어온다 — Slide 26의 "공통 시작 → Branch Point" 패턴과 동일한 구조이나, Branch Point 자체가 위(19.96%)·아래(87.03%)로 훨씬 길게 뻗어 있다는 점이 다르다.
- 1차 Branch Point 위쪽 끝(35.68, 19.96)에서 연결선28(Lane A)이 거의 같은 좌표(35.62, 19.70)로 이어진다.
- Lane A(28) 경로 중간 X≈69.95%(Lane A 전체 폭 35.62~76.33%의 후반부) 지점에서 연결선30(수직)이 아래로 갈라져 나가고, 연결선31(수평)로 다시 이어진다 — **Lane A 내부에서도 재분기가 발생하는 실측 사례**로, 재분기가 항상 "하단 Lane(2세대)"에서만 일어나는 것은 아님을 보여준다.
- 1차 Branch Point 아래쪽 끝(35.68, 87.03)에서 연결선19(Lane C)가 거의 같은 좌표(35.68, 86.88)로 이어지고, 연결선19의 끝점(51.73, 86.88)은 연결선18(2차 Branch Point 수직 브래킷, X51.79%, Y69.03~101.25%)의 Y범위 안에 위치한다 — Lane C가 2차 Branch Point로 이어지는 구조다.
- 2차 Branch Point(18) 위쪽 끝(51.79, 69.03)에서 연결선22가, 아래쪽 끝(51.79, 101.25)에서 연결선12가 각각 이어지며, 이 둘은 각각 Node 자리(gap)를 두고 연결선21·연결선20으로 이어져 최종 2개 결과물 경로를 이룬다 — Slide 26의 "Branch Point → Lane 세그먼트1 → Node 자리 → Lane 세그먼트2" 패턴이 2차 분기에서도 동일하게 반복된다.
- 연결선29(X38.73~89.93%, Y49.57%)는 1차 Branch Point의 Y(49.31~49.68%)와 거의 같은 높이에서 별도로 뻗어 나가는 긴 수평선이지만, 다른 연결선과 endpoint가 명확히 맞닿는 지점이 이 인스턴스만으로는 확인되지 않는다 — **원인을 추정하지 않고 관찰된 실측 사실로만 남긴다**(1차 Branch Point가 2-way가 아니라 3-way일 가능성을 보여주는 정황이나, 이 선이 실제로 어떤 Node로 연결되는지는 미확정).
- Node Box 1("contents")은 1차 Branch Point 상단(X35.68%, Y19.96%)과 가로 약 1.35%p 간격으로 인접하고 그 Y(19.96%)가 Box 1의 세로 범위(16.25%~29.32%) 안에 든다. Node Box 2("COSOLUS(2세대)")는 1차 Branch Point 하반(연결선26, Y49.31%~87.03%)의 Y범위 안에 위치가 겹친다. 다만 두 Box의 테두리가 위 연결선들과 정확히 접하는 좌표는 확인되지 않으므로, **공간적으로 인접·중첩한다는 사실만 확인되며 Box 자체가 Connector 경로의 일부로 그려진 것은 아니다**(Box는 위 "Node 도형 적용 원칙"이 참고하는 도형 예시일 뿐이다).

## Node 도형 적용 원칙(위 두 실측 사실 종합)
Slide 16처럼 재분기가 없는 Flow Diagram의 Material/Output Node는:
1. 연결 구조(Trunk/Branch Point/Lane 세그먼트 위치·간격)는 **Slide 26**의 실측값을 그대로 따르고,
2. Node를 실제 도형으로 표현할 때의 형태(채워진 둥근 사각형, 폭 12.27%×높이 13.06% 비율)는 **Slide 25**에서 실측된 유일한 Node 도형 예시를 형태 기준으로 참고한다(색상은 제외, 위 "색상 제외" 참조).

## Body Box 높이 보정(with-support 변형 사용 시)
위 % 값은 Supporting Message가 없는 non-support Body Box(521px 높이) 기준이다. Slide 16처럼 Supporting Message가 있는 with-support 변형(478px 높이)에서는 세로 방향에만 `478/521 ≈ 0.9174` 배율을 곱해 사용한다(가로는 폭 변화가 없으므로 그대로). 이는 새 비율을 만드는 것이 아니라, 실측 비율을 더 작은 가용 높이에 선형으로 맞추는 환산이다.

## flow-diagram-rules.md와의 관계
`flow-diagram-rules.md`의 "Region Map(비율 기준)" 절은 이 실측값을 이미 한 번 일반화한 2차 설명이며 계속 참고 설명으로 남긴다. 다만 **실제 좌표를 산출할 때는 이 문서(Implementation Reference)를 1차 소스로 사용**하고, 두 문서의 수치가 서로 다르면 이 문서의 실측값을 따른다(적용 규칙은 `flow-diagram-rules.md` §0, `web-ppt-generator/SKILL.md`에 반영).
