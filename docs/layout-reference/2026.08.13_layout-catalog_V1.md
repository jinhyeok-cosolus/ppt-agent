# COSOLUS PPT Layout Catalog

> 본 문서는 `2026.08.13_ppt_layout_set__V3.pptx`의 레이아웃 구조를
> PPT 제작 에이전트가 빠르게 선택·참조할 수 있도록 정리한 카탈로그이다.
> 실제 디자인 스타일을 정의하는 문서가 아니며, Hard Rule 및 Visual Style보다 우선하지 않는다.

## 적용 우선순위
1. Hard Rule
2. Slide-specific Design Rule (존재하는 경우)
3. Layout Catalog / Selected Layout Reference
4. Visual Style
5. Content Visualization Freedom

## 레이아웃 선택 원칙
- 레이아웃은 콘텐츠의 의미, 정보량, 관계 구조에 따라 선택한다.
- Layout Reference를 선택한 경우, Reference의 공간 분할, 요소 배치, 크기 비율, 정렬, 간격, 정보 밀도를 우선적으로 재현한다.
- Reference를 단순 참고로만 취급해 새로운 레이아웃으로 임의 재해석하지 않는다 — 콘텐츠만 새 내용으로 치환하고 구조는 Reference를 그대로 따른다.
- 공통 요소(CI, Sub Message, 구분선, Section Label, Main Title, 페이지 번호 등)는 Reference가 아니라 Hard Rule을 우선 적용한다.
- Design System(색상·타이포그래피·차트/이미지 스타일 등)은 선택된 Layout의 구조(공간 분할·배치·비율)를 변경하지 않는 범위 안에서만 적용한다.
- 콘텐츠를 레이아웃에 억지로 맞추지 않는다.
- 적합한 구조가 여러 개라면 더 단순하고 정보 위계가 명확한 레이아웃을 우선한다.
- 동일한 유형의 슬라이드에서는 가능한 한 동일하거나 유사한 레이아웃 계열을 유지한다.
- 표/그래프/이미지 사용 여부는 Content Visualization Freedom 범위 안에서 판단한다.

## 사용 규칙
- 에이전트는 슬라이드 콘텐츠 유형을 먼저 판단한 뒤 이 카탈로그에서 적합한 레이아웃 후보를 선택한다.
- Slide-specific Design Rule에 권장 레이아웃이 지정되어 있으면 해당 후보를 우선한다.
- 카탈로그에 적합한 구조가 없을 때만 기존 레이아웃을 조합하거나 최소 범위에서 변형한다.
- 변형 시에도 Hard Rule과 Visual Style을 반드시 유지한다.
- 원본 PPTX는 사람이 구조를 시각적으로 확인하기 위한 Reference로 유지하고, 본 MD는 에이전트의 빠른 선택용 인덱스로 사용한다.
