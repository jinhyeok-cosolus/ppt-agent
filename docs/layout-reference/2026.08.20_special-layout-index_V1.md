# 콘텐츠 구조별 특수 Layout Reference — 선택 인덱스

> `docs/slide-design-rules/`에 누적되는 콘텐츠 구조별 특수 Layout Reference(표지 전용 제외)의 **경량 탐색 인덱스**다. `layout-catalog_V1.md`(L01~L33 범용 카탈로그)와 같은 역할 — Layout Routing 시 원본 MD(각 300~480줄)를 전부 열어보지 않고, 이 표에서 먼저 후보를 1~2개로 좁힌 뒤 그 후보만 상세 Read한다.
>
> **원본 우선(Source of Truth)**: 이 표의 Use When/Do Not Use When은 각 원본 Layout MD 상단 "Use When"/"Do Not Use When" 절을 그대로 옮긴 것이며, 이 표 자체가 새로운 판단 기준을 만들지 않는다. 실제 세부 스펙(좌표·비율·색상·Variant 세부 규칙 등)은 이 표에 없으므로 후보를 확정한 뒤에는 반드시 원본 MD를 열어 대조한다. 원본 MD가 갱신되면 이 표도 함께 갱신해야 한다(불일치 발견 시 원본이 항상 우선).
>
> 표지(Cover) 슬라이드는 이 표 대상이 아니다 — 항상 [`01_cover_design_V2.md`](../slide-design-rules/01_cover_design_V2.md)를 우선 적용한다(design-rules.md "표지 전용" 참조).

## 탐색 절차
1. `slide-structuring`(Phase B)이 판단한 **Relationship 유형**(독립·대등 / 복수 비교 / Before-After / 순환 / 순차·공정 / 원인→결과 / 단계별 변화 / 구성요소별 기여도 등)을 확인한다.
2. 아래 표의 **Category** 열에서 그 Relationship과 맞는 행을 먼저 좁힌다.
3. 좁혀진 후보들의 **Use When/Do Not Use When**을 대조해 1~2개로 최종 후보를 압축한다.
4. 최종 후보 1~2개에 한해서만 **원본 MD 경로**를 열어 상세 스펙(구조·비율·Variant 등)을 확인한다 — 후보가 아닌 나머지 문서는 열지 않는다.
5. 표의 어떤 행도 Use When에 해당하지 않으면 `layout-catalog_V1.md`(L01~L33)로 넘어간다(design-rules.md "레이아웃 선택 기준" 5번 참조).

## 참고
- 이 표들은 각 원본 MD가 "Hard Rule > Claude PPT Design System > 해당 Layout Reference" 우선순위를 자체 명시하는 것과 정합한다 — `design-rules.md`의 전체 우선순위 체계(1~4순위)를 대체하지 않는다.
- Layout을 고를 때는 **콘텐츠 항목 개수보다 정보 관계(Relationship)를 우선 판단**한다 — `design-rules.md` "Layout Routing 판단 순서 — Relationship 우선" 참조.
- Visual + Insight Layout은 조건이 가장 넓은 범용 Family이므로, 더 구체적인 전용 Layout의 조건에 먼저 해당하는지 확인한 뒤에만 후보로 선택한다.
- 이 인덱스에 없는 콘텐츠 구조는 `layout-catalog_V1.md`(L01~L33 범용 카탈로그)에서 선택한다.
